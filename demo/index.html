How to read this

  • Each row is one 2 s EEG window (8 of 129 channels shown, one shared amplitude scale set to the 90th percentile of |z|, so larger excursions clip). To its right are the five candidates the model ranks highest, best first. The correct one — when it makes the top five — is outlined and marked ✓ correct.
  • Bars show cosine similarity in the shared EEG–video space, positioned within the common range spanned by every candidate on this page (-0.28 to +0.26). Absolute values are small, often negative, and cluster tightly — retrieval only uses the ordering, and the exact value is printed beside each bar.
  • Chance is K / N: with 35 scene candidates, a random model gets Top-1 right 2.9% of the time. The "× chance" figure is the honest measure of the effect.
  • This is EEG→video only. The reverse direction (given a scene, find the EEG of someone watching it) is far weaker on this checkpoint — Top-1 about 2× chance, and Top-10 below chance. Don't read this page as evidence that both directions work.
  • The model has a favourite answer. It names scene 0 · 0:00–0:10 · 2 shots as its first guess for 40.6% of all 10908 windows, though that is the correct answer only 5.0% of the time (uniform would be 2.9%). That is why the same thumbnail recurs at rank 1 in the rows above. It does not change the Top-K figures above — but a large share of first guesses landing on one attractor is something those figures alone would not tell you.
  • Rows are chosen to include successes and failures; they are illustrative, not a random sample. The aggregate numbers above are over all 10908 windows.
  • Every number here is recomputed from the exported embeddings and checked against retrieval_warmstart_lr3e4_retrain_jul22_ep299_test.json before this page is written. See §3.10 of experiments/clip_pretraining/scene_clip_from_checkpoint/RESULTS.md.
